1. WEB ANALYTICS
Web Analytics is the process of collecting, measuring, analyzing, and reporting website data to understand user behavior and improve website performance.

Real-Life Example
An online shopping website wants to know:

  • How many visitors visit daily?
  • Which products are viewed most?
  • Why customers leave without purchasing?

Web analytics helps answer these questions.

A. Metrics
Metrics are measurable quantities used to track website performance.

Common Web Analytics Metrics

MetricMeaning
Page ViewsNumber of pages viewed
UsersNumber of unique visitors
SessionsNumber of visits
Bounce RatePercentage leaving after one page
Average Session DurationAverage time spent on website
Conversion RatePercentage completing desired action

Example
Suppose a website receives:

  • 1000 visitors
  • 2000 page views

Average Pages per Visitor:

2000/1000=2

Each visitor viewed 2 pages on average.

B. KPIs (Key Performance Indicators)
KPIs are strategic metrics used to evaluate business goals.

Examples

Business GoalKPI
Increase SalesConversion Rate
Improve EngagementAverage Session Duration
Grow AudienceNew Users
Reduce ExitsBounce Rate

Example

An e-commerce website goal:
Increase online sales by 20%.

Relevant KPI:
Conversion Rate

If: 1000 visitors and 50 purchases

Conversion Rate=50/1000×100 = 5%

C. User Behaviour Analysis
Study of how users interact with a website.

Questions Answered

  • Which pages are visited most?
  • Where do users leave?
  • Which products attract attention?
  • What path do users follow?

2. BASICS OF INFORMATION RETRIEVAL (IR)
Information Retrieval (IR) is the process of finding relevant information from a large collection of data.

Example
When a user searches:
"Best smartphone under ₹20,000"
Google retrieves relevant web pages.

IR Process
User Query
↓
Search System
↓
Document Matching
↓
Ranking
↓
Results Displayed

A. Indexing
Indexing is the process of organizing documents so they can be searched efficiently.

Library Example
Instead of searching every book manually, a library catalogue stores:

  • Title
  • Author
  • Subject

Similarly, search engines create indexes.

Example
Document:
"Machine learning improves search engines."

Index:

TermDocument
MachineD1
LearningD1
SearchD1
EnginesD1

Advantages

  • Faster search
  • Efficient retrieval
  • Reduced processing time

B. Querying
A query is the user's search request.

Examples

  • "Data Science Books"
  • "Weather in Mumbai"
  • "Best laptop 2025"

Types of Queries

Informational
Example:
"What is Artificial Intelligence?"

Navigational
Example:
"Facebook Login"

Transactional
Example:
"Buy iPhone 16"

C. Ranking
Ranking determines the order of search results based on relevance.

Example
Query:
"Python Programming"

Result A:
Python Tutorial

Result B:
Python snake

Result A receives higher rank because it is more relevant.

Factors Affecting Ranking

  • Keyword relevance
  • Page quality
  • Popularity
  • User behaviour
  • Freshness of content

4. COMPONENTS OF INFORMATION RETRIEVAL SYSTEMS

A. Document Representation
Converting documents into machine-understandable formats.

Example: Document
"Artificial Intelligence enables smart systems."

After processing:

TermFrequency
Artificial1
Intelligence1
Smart1
Systems1

Techniques

  • Tokenization
  • Stop-word removal
  • Stemming
  • Vector representation

Example

Sentence:
"The computer is computing data."

After stemming:
computer
compute
data

B. Retrieval Models
Methods used to determine relevance between query and documents.

1. Boolean Model

Uses:

  • AND
  • OR
  • NOT

Example:

Data AND Mining
Returns documents containing both words.

2. Vector Space Model

Represents documents as vectors.
Measures similarity using mathematical calculations.

Example: Query: "Machine Learning"

Documents with more matching terms receive higher scores.

3. Probabilistic Model

Calculates probability that a document is relevant.
Higher probability = Higher rank.

Short Answer Questions

1. Define Web Analytics.

Web Analytics is the process of collecting, measuring, analyzing, and reporting website data to understand user behavior and improve website performance. It helps organizations make data-driven decisions to enhance user experience and achieve business goals.

Example: An online shopping website analyzes visitor data to identify why customers leave without making purchases.

2. What is a KPI?

A Key Performance Indicator (KPI) is a measurable value used to evaluate how effectively an organization is achieving its objectives and goals.

Examples:

  • Conversion Rate
  • Bounce Rate
  • Revenue Growth
  • Customer Retention Rate

Example: If an e-commerce website aims to increase sales, its KPI may be the conversion rate.

3. Explain Indexing in Information Retrieval.

Indexing is the process of organizing and storing information from documents in a structured format so that relevant documents can be retrieved quickly when a user submits a query.
Instead of searching every document individually, the system searches the index.

Example:
Document:
"Machine Learning improves search engines."

Index:

TermDocument
MachineD1
LearningD1
SearchD1
EnginesD1

This allows faster searching.

4. What is Clickstream Data?
Clickstream data is the sequence of clicks and pages visited by a user during a browsing session on a website.
It records the path followed by users and helps analyze navigation behavior.

Example:

↓

↓

Checkout

Businesses use clickstream data to understand user preferences and improve website design.

5. Define Retrieval Model.

A retrieval model is a mathematical framework used in Information Retrieval systems to determine the relevance of documents to a user's query.

It helps rank documents according to how well they match the search request.

Examples:

  • Boolean Model
  • Vector Space Model
  • Probabilistic Model

5. Explain Applications of Information Retrieval in Digital Marketing and Search Engines.

Information Retrieval techniques are widely used to locate, organize, and rank relevant information from large data collections.

A. Applications in Search Engines
Search engines use IR techniques to provide relevant search results.

Working

  1. Crawl web pages.
  2. Create indexes.
  3. Process user queries.
  4. Retrieve matching pages.
  5. Rank results.

Example
Search Query:
"Digital Marketing Course"
The search engine retrieves and ranks relevant web pages.

Benefits

  • Fast information access
  • Accurate search results
  • Improved user experience

B. Applications in Digital Marketing
Digital marketers use IR techniques to understand customer interests and improve online visibility.

Uses
1. Search Engine Optimization (SEO)
Businesses optimize content using popular keywords.

Example:
A laptop company targets keywords such as:

  • Best laptop for students
  • Affordable laptops

2. Keyword Analysis
Marketers identify frequently searched terms.

Benefits:

  • Better content creation
  • Improved website traffic

3. Online Advertising
Advertisements are displayed based on user searches and interests.

Example:
A user searching for "running shoes" may see sports shoe advertisements.

C. Applications in User Behaviour Analysis
IR systems analyze:

  • Search patterns
  • Browsing history
  • Clickstream data
  • Purchase behavior

Example

Users searching for "Wireless Earbuds" frequently buy "Phone Covers."

The website recommends phone covers to similar users.
Conclusion
Information Retrieval plays a crucial role in:

  • Search engines
  • Digital marketing
  • User behavior analysis

It helps organizations deliver relevant information, improve customer experiences, and make informed business decisions.
