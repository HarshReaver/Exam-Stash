Module 6: Real-Time Web Analytics and Intelligent Systems

Subject: Web Analytics and Information Retrieval

1. Introduction to Real-Time Web Analytics

Definition
Real-Time Web Analytics refers to the collection, processing, analysis, and visualization of web data as it is generated, enabling immediate insights and decision-making.

Objectives

  • Monitor website performance instantly.
  • Detect user behavior in real time.
  • Support rapid business decisions.
  • Improve user engagement and conversions.

Examples

  • Monitoring live website traffic.
  • Real-time fraud detection.
  • Tracking ongoing marketing campaigns.

2. Real-Time Analytics and Stream Processing

Definition

Real-Time Analytics is the analysis of data immediately after it is generated, while Stream Processing continuously processes incoming data streams.

Architecture

Data Sources
↓
Data Stream
↓
Stream Processing Engine
↓
Analytics Dashboard
↓
Decision Making

Examples

  • Live stock market analysis.
  • Real-time website monitoring.
  • Social media trend analysis.

Benefits

  • Faster decision-making.
  • Immediate anomaly detection.
  • Improved customer experience.

3. Web Data Streams and Clickstream Data

Web Data Streams
Continuous flow of web-generated data.

Examples

  • Page views
  • Clicks
  • Searches
  • Purchases

Clickstream Data

Definition
A sequence of pages and actions performed by a user during a browsing session.

Example

Homepage
↓
Product Page
↓
Add to Cart
↓
Checkout

Applications

  • User journey analysis
  • Personalization
  • Recommendation systems

4. Stream Processing Concepts

Definition

Stream processing involves processing data continuously as it arrives.

Key Concepts

Event Streams

Continuous sequence of events.

Window Processing

Processes data over fixed time intervals.

Event Time

Actual time when an event occurred.

Real-Time Computation

Instant processing without storing data first.

Example

A website calculates the number of active users every minute.

9. Introduction to Semantic Search

Definition

Semantic Search aims to understand the meaning and intent behind search queries rather than matching exact keywords.

Traditional Search

Query:

Best phone under ₹20,000

Matches exact keywords.

Semantic Search

Understands that:

  • Smartphone
  • Mobile phone
  • Cell phone

have similar meanings.

Benefits

  • Better search accuracy
  • Improved user satisfaction
  • Context-aware results

10. Embeddings in Semantic Search

Definition
Embeddings are numerical vector representations of words, sentences, or documents that capture semantic meaning.

Example

Words with similar meanings have similar vectors.

King ≈ Queen
Doctor ≈ Physician

Applications

  • Semantic search
  • Recommendation systems
  • Chatbots
  • Question answering systems

11. Word2Vec

Definition

Word2Vec is a neural network-based technique that converts words into dense vector representations.

Features

  • Captures word relationships
  • Learns semantic similarity
  • Reduces dimensionality

Example

King - Man + Woman ≈ Queen

Applications

  • NLP
  • Search engines
  • Text classification

12. BERT (Bidirectional Encoder Representations from Transformers)

Definition
BERT is a deep learning language model developed by Google that understands context by analyzing words in both directions.

Features

  • Context-aware understanding
  • Bidirectional processing
  • High search accuracy

Example

Query:

Apple

BERT determines whether "Apple" refers to:

  • Fruit
  • Technology company

based on context.

Applications

  • Google Search
  • Chatbots
  • Question Answering
  • Semantic Search

13. Ethical and Privacy Issues in Web Analytics

A) Data Privacy
Protecting personal information from unauthorized access.

Examples

B) User Consent

C) Cookie Policies

Organizations must disclose:

14. GDPR Compliance

Definition

General Data Protection Regulation (GDPR) is a European Union regulation that protects personal data and privacy.

Key Principles

  • User Consent
  • Data Transparency
  • Right to Access Data
  • Right to Erasure ("Right to be Forgotten")

Benefits

  • Increased user trust
  • Better privacy protection

15. CCPA Compliance

Definition

California Consumer Privacy Act (CCPA) protects privacy rights of California residents.

User Rights

  • Know what data is collected
  • Request data deletion
  • Opt-out of data selling

Importance

Improves transparency and user control over personal data.

Module 6: Real-Time Web Analytics and Intelligent Systems

Answers to Short Questions (2–3 Marks)

1. Define Real-Time Web Analytics.

Answer:
Real-Time Web Analytics is the process of collecting, analyzing, and monitoring website data as it is generated, allowing organizations to make immediate decisions based on current user activities.

2. What is Stream Processing?

Answer:
Stream Processing is the continuous processing and analysis of data as it arrives from various sources without waiting for the complete dataset.

Example: Monitoring website visitors in real time.

3. Define Clickstream Data.

Answer:
Clickstream Data is the sequence of clicks and pages visited by a user during a browsing session on a website.

Example:

Homepage → Product Page → Cart → Checkout

4. What is Funnel Analysis?

Answer:
Funnel Analysis is a technique used to track users through different stages of a process and identify where users drop out before completing a desired action.

5. Define User Journey Tracking.

Answer:
User Journey Tracking is the process of monitoring and analyzing the path users follow while interacting with a website or application.

6. What is Social Media Analytics?

Answer:
Social Media Analytics involves collecting and analyzing data from social media platforms to measure engagement, reach, sentiment, and campaign performance.

7. What is Mobile Analytics?

Answer:
Mobile Analytics is the measurement and analysis of user behavior and interactions within mobile applications and mobile websites.

8. Define Semantic Search.

Answer:
Semantic Search is a search technique that understands the meaning and context of a query rather than relying only on exact keyword matching.

9. What are Embeddings?

Answer:
Embeddings are numerical vector representations of words, sentences, or documents that capture semantic relationships and meanings.

10. What is Word2Vec?

Answer:
Word2Vec is a neural network-based technique that converts words into vector representations, allowing machines to understand semantic similarities between words.

11. Define BERT.

Answer:
BERT (Bidirectional Encoder Representations from Transformers) is a deep learning language model developed by Google that understands the context of words by analyzing text in both directions.

12. What is User Consent?

Answer:
User Consent is the permission granted by users before collecting, storing, or processing their personal data.

13. What is GDPR?

Answer:
GDPR (General Data Protection Regulation) is a European Union privacy law that protects personal data and gives users greater control over their information.

14. What is CCPA?

Answer:
CCPA (California Consumer Privacy Act) is a privacy regulation that gives California residents rights regarding the collection and use of their personal information.

15. State Any Two Applications of Real-Time Web Analytics.

Answer:

  1. Real-time website performance monitoring.
  2. Clickstream analysis for user behavior tracking.
