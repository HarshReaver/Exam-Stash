12. Use the Data Science process model to show how data is systematically collected, cleaned, and analyzed to generate meaningful outcomes in practical applications.

2. Utilize data preprocessing techniques to illustrate why cleaning, transforming, and preparing raw data are necessary during Exploratory Data Analysis.

10. Demonstrate how summary statistics such as mean, median, variance, and quartiles help in understanding data patterns during Exploratory Data Analysis.

11. Examine the need for data standardization in machine learning applications and infer how it improves model training and feature comparability.

12. Employ visualization techniques to identify patterns, trends, and anomalies during Exploratory Data Analysis.

A loan approval system shows unfair predictions for certain applicants. Investigate how Exploratory Data Analysis can identify biased data and analyze its effect on fairness in predictions.

16. Implement a complete data preprocessing workflow used in Exploratory Data Analysis, showing how data cleaning, transformation, handling missing values, and scaling prepare the dataset for model building.

17. Evaluate various methods of handling missing values and conclude their impact on data quality, model accuracy, and dataset reliability.

18. Apply visualization techniques such as histogram, scatter plot, and box plot to prevent incorrect outlier removal during data preprocessing.

19. A hospital dataset contains missing, inconsistent, and highly skewed patient records. Assess the dataset and conclude a suitable Exploratory Data Analysis and preprocessing strategy to improve decision-making accuracy.

20. Utilize a real-time dataset example to demonstrate the importance of Exploratory Data Analysis in supporting accurate and data-driven decision making.

21. A smart-healthcare system relies on patient data for decision-making. Examine how improper Exploratory Data Analysis can affect ethical considerations, safety outcomes, and system reliability.
