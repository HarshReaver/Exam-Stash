Module 4: Information Retrieval and Search Engine Analytics

1. Introduction to Information Retrieval (IR) Systems

Information Retrieval (IR) is the process of obtaining relevant information or documents from a large collection based on a user's query.

Objectives of Information Retrieval

  • Retrieve relevant documents efficiently.
  • Minimize irrelevant results.
  • Improve search accuracy.
  • Support user information needs.

Examples of IR Systems

  • Google Search
  • Bing Search
  • Digital Libraries
  • E-commerce Product Search
  • Academic Search Engines

Example

When a user searches "Machine Learning Notes", the IR system retrieves the most relevant documents from millions of webpages.

3. Document Representation and Preprocessing

Before searching, documents must be converted into a machine-readable format.

3.1 Tokenization
Breaking text into individual words or terms called tokens.

Example

Text:
Web Analytics improves website performance.

Tokens:
Web, Analytics, improves, website, performance

3.2 Stop Word Removal
Removing common words that carry little meaning.

Examples

  • is
  • am
  • are
  • the
  • and

Example

Original Sentence:
The web analytics system is useful.

After Stop Word Removal:
web analytics system useful

3.3 Stemming
Reducing words to their root form.

Example

WordStem
ComputingComput
ComputedComput
ComputerComput

3.4 Lemmatization
Converting words to their meaningful base form.

Example

WordLemma
RunningRun
BetterGood
StudiesStudy

Applications

  • Recommendation systems

5. Term Frequency – Inverse Document Frequency (TF-IDF)

TF-IDF measures the importance of a term within a document relative to a collection of documents.

A) Term Frequency (TF)

Measures how often a term appears in a document.

Formula:

TF = Number of times term appears / Total terms in document

Example:

Document:
SEO SEO Analytics

TF(SEO):

TF = 2/3

B) Inverse Document Frequency (IDF)

Measures how unique or rare a term is across all documents.

Formula:

IDF = log(N / DF)

Where:

  • N = Total number of documents
  • DF = Number of documents containing the term

TF-IDF Formula

TF-IDF = TF × IDF

Importance

  • Highlights important keywords
  • Improves document ranking
  • Widely used in search engines

6. Introduction to Link Analysis

Link analysis evaluates relationships among webpages using hyperlinks.

Purpose

  • Determine webpage importance.
  • Improve search result ranking.

Example
If many websites link to a webpage, search engines consider it more authoritative.

7. PageRank Algorithm (Conceptual Understanding)

PageRank is Google's link analysis algorithm that ranks webpages based on the quantity and quality of incoming links.

Working Principle

A page receives higher rank when:

  • More pages link to it.
  • High-quality pages link to it.

Example

Page A → Page B
Page C → Page B
Page D → Page B

Since Page B receives multiple links, its PageRank increases.

Advantages

  • Measures authority.
  • Improves result quality.
  • Reduces manipulation.

8. HITS Algorithm (Conceptual Overview)

HITS (Hyperlink-Induced Topic Search) identifies two types of webpages:

Hub Pages

Pages containing links to many useful resources.

Authority Pages

Pages containing valuable content.

Example

University Website:

  • Homepage → Hub
  • Research Article → Authority

Working Principle

Good hubs point to good authorities, and good authorities are pointed to by good hubs.

Comparison: PageRank vs HITS

FeaturePageRankHITS
FocusImportance of PagesHubs and Authorities
ComputationEntire WebQuery Specific
OutputSingle ScoreHub and Authority Scores
Used ByGoogleAcademic IR Systems

Related Terms

User History Based Expansion

  • Retrieves more relevant documents.
  • Handles vocabulary differences.

12. BM25 Ranking Model (Conceptual Overview)
BM25 (Best Matching 25) is an advanced ranking function used in modern search engines to estimate document relevance.

Features

  • Considers term frequency.
  • Considers document length.
  • Handles keyword saturation.
  • Improves ranking accuracy.

Example

Query:
Information Retrieval

BM25 ranks documents higher if:

  • Query terms appear frequently.
  • Document is relevant.
  • Document length is appropriate.

Applications

  • Search engines
  • Digital libraries
  • Enterprise search systems

Answers to Short Questions (2–3 Marks)

1. Define Information Retrieval System.

An Information Retrieval (IR) System is a system that searches, retrieves, and presents relevant documents or information from a large collection based on a user's query.

2. What is Document Preprocessing?

Document preprocessing is the process of cleaning and transforming raw text into a structured format suitable for indexing and retrieval. It includes tokenization, stop-word removal, stemming, and lemmatization.

3. What is Tokenization?

Tokenization is the process of breaking text into smaller units called tokens, usually words or terms.

Example:
Sentence: "Information Retrieval System"
Tokens: Information, Retrieval, System

4. Define TF-IDF.

TF-IDF (Term Frequency-Inverse Document Frequency) is a statistical measure used to determine the importance of a term in a document relative to a collection of documents.

Formula: TF−IDF=TF×IDF

5. What is the Vector Space Model?

The Vector Space Model (VSM) is a mathematical model that represents documents and queries as vectors in a multidimensional space and measures their similarity for retrieval.

6. What is Link Analysis?

Link analysis is a technique used to evaluate relationships among webpages through hyperlinks to determine their importance and authority.

7. Define PageRank.

PageRank is a link analysis algorithm developed by Google that ranks webpages based on the number and quality of incoming links.

8. What is the HITS Algorithm?

HITS (Hyperlink-Induced Topic Search) is a link analysis algorithm that identifies webpages as hubs and authorities based on hyperlink structures.

9. What are the Types of Search Intent?

The three main types of search intent are:

  1. Informational Intent – seeking information.
  2. Navigational Intent – searching for a specific website.
  3. Transactional Intent – intending to perform an action or purchase.

10. What is Query Expansion?

Query expansion is the process of enhancing a user's search query by adding related words, synonyms, or phrases to improve search results.

11. Define BM25.

BM25 (Best Matching 25) is a probabilistic ranking model used by search engines to estimate the relevance of documents to a search query.

12. State the Role of SEO in Information Retrieval.

SEO helps search engines crawl, index, and rank webpages effectively, thereby improving the retrieval of relevant information for users.
