# Night Before

Previous-year papers (ISE and ESE), question banks and notes for TCET IT, semesters III to VII, shared by Harsh from IT Batch 2027. Live address (once published): https://pyq.harver.in

Not an official TCET site. The syllabus may have changed since Batch 2027.

## How it is built

Plain HTML, CSS and JavaScript on GitHub Pages. The pages are generated by small Python scripts from a list of files:

- `tools/catalog.py`: every subject and file, with semesters, years and exam names.
- `tools/prepare.py`: makes the public copies in `files/` (document properties removed, paper sets cut out of the combined PDFs) and the page images in `pages/`.
- `tools/convert.py`: turns the Excel question banks and Word notes into readable pages.
- `tools/build.py`: writes every HTML page, `sitemap.xml`, `robots.txt` and `llms.txt`.
- `tools/render_assets.ps1`: renders the favicon PNGs and `og-image.jpg`.

To add a file: add a line to `tools/catalog.py`, then run

```
python tools/prepare.py
python tools/build.py
```

Design reasons are in `DESIGN.md`.
